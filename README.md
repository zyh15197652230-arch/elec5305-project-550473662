# elec5305-project-550473662
This project aims to develop, simulate and evaluate a Wiener filter voice enhancement system based on voice activity detection (VAD), which is implemented in MATLAB. The main research problem is to quantitatively analyze the fluctuations of the effectiveness of Wiener filters under different types of noise: specifically, steady-state noise (such as constant white noise generated by air conditioners) and non-steady-state noise (such as fluctuating street background noise or noise in crowded areas).
Improving voice recognition in noisy environments is still a key challenge in the fields of telecommunications, hearing aid design and voice control human-computer interface. This project aims to propose an efficient and lightweight MATLAB solution by isolating and evaluating the performance of algorithms in different noise environments, while better understanding the basic limitations of classical statistical signal processing methods in dynamic acoustic environments.
